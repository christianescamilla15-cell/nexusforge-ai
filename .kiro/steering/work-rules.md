# Work Rules

## Critical Rules
1. Read ALL affected files before changing anything
2. Plan the change before writing code
3. Make the minimum change needed
4. Build/test locally before pushing
5. Never commit secrets (.env, credentials, API keys)
6. Quality over speed — correct code > fast code

## Development Flow
1. Understand the existing code and patterns
2. Plan the minimal change needed
3. Implement and test locally
4. Review your own diff before committing
5. Push and verify CI passes
