# Git Workflow

## Commits
- Imperative mood: "add feature" not "added feature"
- Prefix: feat/fix/refactor/docs/test/chore
- Reference issue number when applicable

## Branches
- main: production-ready
- feature/*: new features
- fix/*: bug fixes
- Never commit directly to main for team projects

## Reviews
- Self-review diff before pushing
- Run tests locally before PR
- Address all review comments before merge
